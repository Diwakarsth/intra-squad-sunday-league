# v1.0.2 Direct Photo Upload

Cloudinary configuration is already included in this package.

- Cloud name: `w4yvxtsl`
- Unsigned upload preset: `intra_squad_gallery`

No Cloudinary API secret is stored in the website.

After uploading the files to GitHub and deployment completes:
1. Log in as Admin.
2. Open Gallery.
3. Select a match.
4. Choose one or more photos from the device.
5. Add an optional caption.
6. Select Upload Photos.

Videos remain link-based.

The Admin Remove Photo button removes the Gallery entry. Permanent deletion of the underlying Cloudinary asset is not performed from the public browser client.
